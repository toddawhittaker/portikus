# Archive

`epics/` holds the working briefs of finished epics, kept for history.
They record the rulings, task splits, and risks as they stood while each
epic was built, and some of those rulings were changed later.

The current rules live in `docs/SPEC.md` and the decision records in
`docs/adr/`. Where a brief and those disagree, SPEC.md and the ADRs win.
