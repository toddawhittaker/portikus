# Logos

Outlined SVGs of the Portikus mark and wordmark for places that cannot use the `NameMark` component (favicon, email, documentation, the identity provider's client logo).

- `portikus-mark-ink.svg`, `portikus-wordmark-ink.svg`: stone `#23211d` (light `ink`) for light grounds.
- `portikus-mark-paper.svg`, `portikus-wordmark-paper.svg`: stone `#ece8df` (dark `ink`) for dark grounds.
- In all four, the room is `#11100e` (`terminal-bg`), the code lines `#3a8a7e` (`mark-code`) and the cursor `#e8c37a` (`terminal-cursor`).
- `portikus-mark-mono-ink.svg` (ink `#23211d`) and `portikus-mark-mono-paper.svg` (ink `#ece8df`): one-colour versions for embossing, single-colour print and watermarks. The code lines and cursor are cut out, so the ground shows through.
- `portikus-mark-compact-ink.svg` and `portikus-mark-compact-paper.svg`: the square 32-unit mark for favicons and sizes of 24px or less, same inks as the full marks.
- The wordmark text is Public Sans 700, converted to outlines, with its cap height at two thirds of the mark's height and its baseline on the top of the base line. Do not retype it.
- Minimum sizes: full mark 32px wide, wordmark 96px wide. Below that, use the compact mark.
