# Portikus

A browser-based development workspace for learning agentic software
development. Each user gets a real Linux workspace with Git, Docker,
terminals, and coding agents, reached through an ordinary web browser.

Start with [docs/OVERVIEW.md](docs/OVERVIEW.md). The full design lives in
`docs/VISION.md`, `docs/SPEC.md`, and `docs/STACK.md`.

There is no code yet. The repository is at the design stage.
